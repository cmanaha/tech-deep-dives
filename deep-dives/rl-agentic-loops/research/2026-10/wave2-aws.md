### G1. Does AgentCore Memory's episodic reflection improve task success, measured anywhere first-party? (RESEARCH-GUIDE wave 2 question 7)
- Yes, once, in an AWS blog (Tier 2, vendor performance claim). https://aws.amazon.com/blogs/machine-learning/build-agents-to-learn-from-experiences-using-amazon-bedrock-agentcore-episodic-memory/ (published 21 JAN 2026; accessed 2026-10-30). Setup, verbatim: "We evaluated Amazon Bedrock AgentCore episodic memory on real-world goal completion benchmarks from the retail and airline domain (sampled from τ2-bench)." "For the baseline, we ran the agent (built with Anthropic's Claude 3.7) without interacting with the memory component." "The baseline agent first processes a set of historical customer interactions, which become the source for memory extraction." "Each query is attempted four times in parallel." "Pass^k measures the percentage of tasks where the agent succeeded in at least k out of four attempts". Memory reached the agent through two custom retrieval tools, `retrieve_exemplars` (episodes as in-context examples) and `retrieve_reflections` (cross-episode reflections).
- Table (Pass^1 / Pass^2 / Pass^3). Retail: baseline 65.80% / 49.70% / 42.10%; episodes as ICL examples 69.30% / 53.80% / 43.40%; cross-episode reflection 77.20% / 64.30% / 55.70%. Airline: baseline 47% / 33.30% / 24%; episodes 55.00% / 46.70% / 43.00%; reflection 58% / 46% / 41%. Text: "Cross-episode reflection improved Pass^1 by +11.4% and Pass^3 by +13.6% over the baseline" (retail); "the airline domain ... benefits more from episodes as examples, which achieved the highest Pass^3 (43.0% vs 41.0% for reflection)".
- Arithmetic [derived]: retail reflection 77.2 - 65.8 = 11.4 and 55.7 - 42.1 = 13.6, so the blog's "+11.4%" and "+13.6%" are percentage points, not relative gains. Airline Pass^3: 43.0 - 24 = 19.0 points for episodes, 41 - 24 = 17 points for reflection.
- What it does not show: success over successive episodes (one memory build, then one evaluation; no learning curve); task counts, seeds or confidence intervals; whether the historical interactions overlap the test tasks; which signal labelled episode outcomes (default LLM verdict or not). Pass^k here is the blog's own definition ("at least k out of four"); whether it matches τ2-bench's own metric of the same name was not checked in this pass.
- Register-style entry. Claim: in AWS's own test, retrieving AgentCore episodic memory raised a Claude 3.7 agent's success on tasks sampled from τ2-bench; reflections helped most in retail, episodes in airline. Location: AWS ML blog, section "Performance evaluation". Evidence: as quoted above. Tier 2, vendor performance claim. Use in dive: section 23, one sentence after "a way to learn from history", attributed in the sentence because it is a vendor figure. Proposed text: "In AWS's own test, a Claude 3.7 agent on retail tasks sampled from τ2-bench succeeded at least once in four attempts on 77.2% of tasks with cross-episode reflections against 65.8% without memory [vendor claim]; on airline tasks, stored episodes beat reflections at the stricter at-least-three-of-four bar (43.0% against 41%, baseline 24%).
