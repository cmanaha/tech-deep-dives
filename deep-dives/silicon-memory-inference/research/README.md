# Research — Silicon, Memory, and Modern Inference

During the STAC London 2026 panel prep phase, research materials are staged at the repo root in `research/stac-london-2026/` so they can be referenced by multiple downstream artifacts (the panel itself, this deep dive, and future talks).

Once the panel is delivered, the verified subset of that research migrates into this directory, section-by-section, alongside an accession log that records which notes fed which section and when.

## Structure (once migrated)

```
research/
  stac-panel-notes/        # Full panel prep archive
  raw/                     # Unprocessed excerpts from vendor docs
  extracted/               # Cleaned claims with citations, per section
  experiments/             # Our own measurements (Tier 0)
  accession.md             # Log of what moved from staging into the deep dive
```
