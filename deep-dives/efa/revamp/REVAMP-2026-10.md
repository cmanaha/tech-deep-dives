## The corrections that change a reader's decision

1. P6e-GB200 is listed by the EC2 User Guide under Nitro v6 (EFA v4). The page tells the
   reader to trust Nitro v5. Now only the instance-types page says Nitro v5.
2. Capacity Blocks take no placement group, end at 11:30 UTC and cannot be cancelled.
   The Decision Guide pairs both capacity paths with a cluster placement group, and the
   Pricing section lists the end time and cancellation rule as undocumented.
3. Savings Plans reserve no capacity. Pricing lists them as a way to secure it.
4. GDAKI is no longer an `OFI_NCCL_GIN_TYPE` opt-in. The plugin exports it separately at GIN
   v14, it runs on p5en, p6-b200 and p6-b300 only, and NCCL ranks it below its own GIN proxy,
   so a job gets it only with `NCCL_GIN_TYPE=5` (fact check FC3 L-20, NCCL `gin.cc` L327-L340).
5. Karpenter v1.15 supports the EFA DRA driver (alpha, feature gated). Auto Mode still
   does not. The EKS section says neither does.
6. The EKS AMI rebuild command now silently ignores `nvidia_driver_major_version`.
7. EKS labels every node of a supported type with the network-node layers, through the
   cloud controller manager. The Topology section treats this as unresolved.
8. SageMaker SDK v3.24.0 configures EFA on P5 and P5e. SMDDP last shipped in April 2025
   (inside SMP v2.8.0), not October 2024.
9. NVIDIA k8s-device-plugin v0.19.3 reverted the mofed default; the EKS doc still
   describes v0.19.0. Advice (set it false) stands; the framing changes.
10. Installer 1.51.0 ships driver 3.3.1, libfabric 2.7.0amzn2.0, plugin 1.22.0, so every
    "installer 1.49.0 lacks 0xefa4" argument is out of date.
11. aws-ofi-nccl v1.22.0 disables the eager path by default (`OFI_NCCL_EAGER_MAX_SIZE=-1`).
12. libfabric 2.7.0 makes FI_CONTEXT2 optional on efa-direct while its man page still says
    required: a new documentation-versus-code conflict.

## Rules every group follows

- Edit in place. No changelog voice: no "now", "previously", "no longer", "as of the
  last revision", "Correction:". A version is fine when it is the fact the reader needs.
- Every new or changed number carries a `SourceRef` with tier and accessed date
  (2026-10-23 unless the register records 2026-10-18). Code pins are tags or SHAs.
- Apply the register's replacement text where it is given, re-expressed to the
  section-shape standard. Do not add claims the register does not support.
- Length holds flat or falls. New facts replace stale ones rather than stacking.
- Register rows marked optional or NEW-enhancement go to the backlog below unless they
  correct something a reader would otherwise act on wrongly.
